Instructions

To set the time, increment the timer using the +30s button, then start the timer by pressing the Start button.

The follow times are suggested for a large egg:

  • Soft-boiled: 240 seconds
  • Medium-boiled: 360 seconds
  • Hard-boiled: 540 seconds
