# 🧪 React Warm-Up: Welcome Page

This is a stripped back React app to help you explore what React code looks like and how it relates to what you see in the browser. You don’t need to know React yet - this is just to poke around and make observations.

## 🛠️ Getting Started

### 1. Clone the Repository

Clone the repo down, `cd` into the root folder (`fe-react-morning-task`). **Do not** open up the repo in Visual Studio Code yet.

### 2. Install dependencies:

```
npm install
```

### 3. Start the app

```
npm run dev
```

This will start the development server. You’ll see a local URL in the terminal (usually http://localhost:5173) - click or copy it into your browser.

### 4. Take a look

The browser will tell you what to do next!
