# Testing Morning Task

## Objective

By now you will have passed some tests in last week's sprints that have looked a little something like this:

```js
runTest("some sort of function description", function () {
  check().isEqualTo();
});
```

For today's morning task, we would like you to write your own tests!
In the `morning-task.js` file you will find the skeleton of a function.
Thankfully, the `runTest` and `check` functions have already been imported into the `morning-task.js` file.
You will be using these functions to write tests in a similar fashion to the code snippet above.

## Intructions

1. In the `morning-task.js` file you will find comments outlining the tests you will write that the function must pass.
2. Run the file with `node morning-task.js` and ensure the tests fail.
3. Now add the relevant logic to the function to pass each test one at a time.
4. Make sure you see each test pass before moving on to pass the next one.

## Top Tip !

Errors are your friend! They provide helpful information that allows us to better debug code.
If you see one in the console, read it thoroughly and investigate why it has happened!
